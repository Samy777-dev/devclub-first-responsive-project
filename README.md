# 📱 Projeto Responsivo 1

Um projeto prático de desenvolvimento web Front-End construído com o objetivo de aplicar técnicas avançadas de **Design Responsivo**. A página foi estruturada para garantir uma navegação fluida, visualmente atraente e totalmente adaptável a qualquer resolução de tela.

Este repositório consolida o uso prático de Media Queries e unidades de medida dinâmicas no CSS3.

---

## 🚀 Funcionalidades e Foco Técnico

- **Adaptabilidade Total:** Layout testado e otimizado para smartphones, tablets, notebooks e monitores de desktop.
- **Estilização Moderna:** Uso de propriedades do CSS3 para criar uma interface limpa, com boa distribuição de espaçamentos e tipografia legível.
- **Acessibilidade Estrutural:** Tags HTML aplicadas de forma semântica para garantir uma boa leitura do código pelos navegadores.

---

## 🛠️ Tecnologias Aplicadas

- **HTML5:** Estruturação da página e organização dos blocos de conteúdo.
- **CSS3:** Estilização geral, alinhamentos, e uso de Media Queries para a quebra de layout responsiva.
- **Git & GitHub:** Utilizados para o controle de versão e publicação no portfólio.

---

## 📈 Evolução Técnica

A construção do Projeto Responsivo 1 foi fundamental na minha jornada em **Engenharia de Software** para:
1. Praticar o conceito de flexibilidade visual, garantindo que imagens e textos não quebrem em telas menores.
2. Dominar a organização de regras CSS focadas na experiência do usuário móvel (UX Mobile).
